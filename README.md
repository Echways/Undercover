# Undercover

Telegram-бот для игры в шпиона: 2–16 игроков, шпионов до `игроков / 3`. Все
получают одно слово, шпион — только подсказку к нему. Бот раздаёт роли, ведёт
круги высказываний, собирает голоса и доводит партию до победы одной из сторон.

Режима два:

- **С одного телефона** — `/start`. Состав вводит ведущий, карточки открывает он
  же, вся партия живёт в одном сообщении. Имена можно не придумывать: «Придумать
  имена» раздаст свободным местам зверей — Игуана, Кролик, Сурикат.
- **В группе** — `/undercover`. Лобби собирает состав, слово приходит каждому в
  личку, ходы идут лентой в чате.

Стек: aiogram 3 и aiogram-dialog, Redis под состояние партий, PostgreSQL со
словарём (SQLAlchemy 2 + Alembic), карточки на Pillow.

## Запуск

Нужны Docker с Docker Compose и токен от [@BotFather](https://t.me/BotFather).

```bash
cp .env.example .env                              # BOT_TOKEN и POSTGRES_PASSWORD
docker compose up -d --build                      # бот, PostgreSQL, Redis
docker compose run --rm bot alembic upgrade head  # схема базы
```

Логи — `docker compose logs -f bot`, остановка — `docker compose down` (`-v`,
чтобы удалить данные).

Privacy mode групповому режиму не мешает: команды со слешем Telegram доставляет
боту всегда. Выключить его нужно, только чтобы играть **в группе с одного
телефона**, — там имена вводятся обычными сообщениями: `/mybots` → бот → Bot
Settings → Group Privacy → Turn off.

## Партия в группе

`/undercover` поднимает лобби — одно сообщение с составом и настройками.

«Я в игре» бот подтверждает в личке. Если бот у игрока не открыт, написать
первым он не может — Telegram сам перекинет игрока по ссылке, и после «Старт»
тот вернётся в состав. Двух игроков с одинаковым именем бот разведёт номером.
Ведущий тут же переключает число шпионов, категории слов и длину хода: 30, 45,
60 секунд или без таймера.

«Начать партию» раздаёт карточки в личку и открывает первый ход. Если карточка
не дошла хоть кому-то, партия **не начинается**: бот назовёт этих игроков в
группе и оставит лобби нетронутым — начать вслепую хуже, чем не начать.

Каждый ход приходит новым сообщением, предыдущее замирает отчётом без кнопок: в
живом чате единственное редактируемое сообщение просто уехало бы вверх. С
таймером в карточке идёт отсчёт — раз в пять секунд, чаще Telegram править
сообщения не даёт. Когда время вышло, ход уходит к следующему сам; последний ход
круга остаётся с кнопками, чтобы партия не встала. «Дальше» нажимает ведущий или
тот, чей сейчас ход, — чтобы партия не вставала на отошедшем ведущем. «Ещё круг»
и «Голосовать» решает стол голосованием, «Раскрыть карты» — только ведущий.

Принятые ограничения: бот рассчитан на один экземпляр — отсчёт и блокировки
живут в процессе; после перезапуска таймер молчит, но кнопки работают и партия
доигрывается вручную; состав фиксируется на старте — присоединиться к идущей
партии нельзя.

## Как заканчивается партия

Круг обсуждения заканчивается выбором: ещё круг или голосуем. За одним телефоном
выбирает ведущий одним тапом. В группе жмёт каждый живой игрок, и решает половина
состава плюс один голос; пока идёт подсчёт, он виден в подписи под карточкой.
Если голоса разделились поровну, партия остаётся в обсуждении — круг обратим,
вылет нет.

Голосование за столом с одним телефоном ведёт ведущий: стол договаривается
вслух, ведущий отмечает выбывшего. Передавать телефон второй раз за круг незачем
— тайны на живом столе всё равно нет. В группе каждый живой игрок жмёт кнопку
сам, и до конца голосования видно только счётчик «Проголосовали 3 из 5»: кто за
кого, бот не показывает. Когда сдали все голоса, выбывает тот, кого назвали чаще.
При равенстве идёт переголосование между лидерами; если и оно вничью — никто не
выбывает и партия возвращается к обсуждению.

Выбывший сразу открывает роль, и в группе к вердикту прикладывается расклад
голосов. **Мирные выигрывают, когда среди живых не осталось ни одного шпиона.
Шпионы выигрывают, когда их становится не меньше, чем мирных.** Победитель
попадает в журнал партий.

«Раскрыть карты» осталась и доступна только ведущему: она заканчивает партию
досрочно и показывает карты, но победителя у такой партии нет — в журнале он
остаётся пустым.

Таймера на голосовании нет: партия ждёт последнего голосующего. Если кто-то
пропал, ведущий возвращает стол к обсуждению кнопкой «Вернуться к обсуждению» —
это честнее, чем считать неполный бюллетень и выбить игрока одним голосом из
шести.

## Конфигурация

Всё окружение — в `.env`, шаблон с пояснениями лежит в `.env.example`.
Неверное значение бот сообщает на старте и завершается с кодом 1.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | да | учётные данные базы; их же берёт контейнер `postgres` |
| `POSTGRES_HOST` | да | `postgres` внутри compose, `localhost` при локальном запуске |
| `POSTGRES_PORT` | нет | `5432` по умолчанию |
| `REDIS_URL` | да | одна база под FSM aiogram и состояние партий |
| `LOG_LEVEL` | нет | `INFO` по умолчанию |

## Словарь

Слова в поставку не входят — миграции создают пустые таблицы, наполняет их
владелец бота. Пока слов нет, партия останавливается на «словарь игры пуст».
Таблиц три: `categories` (`slug`, `title`), `words` (`category_id`, `text`,
`difficulty` 1–3) и `spy_hints` (`word_id`, `hint_text`) — подсказка нужна хотя
бы одна.

```sql
WITH category AS (
    INSERT INTO categories (slug, title) VALUES ('food', 'Еда')
    RETURNING id
), word AS (
    INSERT INTO words (category_id, text, difficulty)
    SELECT id, 'борщ', 1 FROM category
    RETURNING id
)
INSERT INTO spy_hints (word_id, hint_text)
SELECT id, 'что-то горячее' FROM word;
```

Консоль: `docker compose exec postgres psql -U undercover -d undercover`.

`title` попадает на кнопку, так что пишется по-человечески: «Еда», а не `food`.
Выбор бот предлагает, когда категорий с активными словами хотя бы две; без
отметок играет по всему словарю. Слово ищется в два шага — случайная категория,
затем случайное слово в ней, — поэтому большой раздел не вытесняет маленький.
Лишнее лучше выключать (`is_active = false`), а не удалять: журнал партий
ссылается на слова.

## Разработка

Нужны [Poetry](https://python-poetry.org/docs/#installation) 2.1+ и Python 3.13
или 3.14.

```bash
poetry install
docker compose up -d postgres redis
poetry run alembic upgrade head
poetry run undercover-bot
```

Конфигурация Alembic живёт в `[tool.alembic]` внутри `pyproject.toml`, а сами
миграции — в пакете (`src/undercover/db/migrations`), поэтому доступны в
контейнере без исходников: `docker compose run --rm bot alembic ...`. Карточки
можно посмотреть без бота: `poetry run python tools/card_preview.py` раскладывает
примеры экранов в `docs/preview`.

Те же команды гоняет CI (плюс порог покрытия: 90% строк, 85% ветвей):

```bash
poetry check --lock               # lock не разошёлся с pyproject
poetry run ruff check .           # линт
poetry run ruff format --check .  # форматирование
poetry run mypy                   # типы, strict
poetry run pytest                 # тесты; -m "not integration" — без Docker
```
