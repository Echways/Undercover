# Undercover

Телеграм-бот для игры в шпиона. 2–16 игроков получают одно слово, шпионы — только
подсказку к нему. Бот раздаёт роли, ведёт круги, считает голоса и объявляет
победителя.

- **С одного телефона** — `/start`. Состав вводит ведущий, партия живёт в одном
  сообщении. Имена можно не придумывать — бот раздаст зверей.
- **В группе** — `/undercover`. Лобби собирает состав, слово приходит в личку,
  ходы идут лентой в чате.

aiogram 3 · aiogram-dialog · Redis · PostgreSQL (SQLAlchemy 2, Alembic) · Pillow.

## Запуск

Docker с Compose и токен от [@BotFather](https://t.me/BotFather).

```bash
cp .env.example .env      # BOT_TOKEN и POSTGRES_PASSWORD
docker compose up -d --build
```

Миграции бот прогоняет сам на старте. Логи — `docker compose logs -f bot`,
остановка — `docker compose down` (`-v` сотрёт данные).

Privacy mode групповому режиму не мешает: команды со слешем доходят всегда.
Выключать его нужно, только чтобы играть в группе с одного телефона — там имена
вводятся обычными сообщениями.

## Партия

Ведущий задаёт режим, число шпионов, категории и длину хода: 30/45/60 секунд или
без таймера. Карточки уходят в личку; если хоть одна не дошла, партия не
начинается — бот назовёт этих игроков и оставит лобби нетронутым.

Ход двигает тот, чей он сейчас, или ведущий. На последнем ходу круга стол решает
голосованием: ещё круг или голосуем. Кто за кого — бот не показывает, виден
только счётчик. При равенстве идёт переголосование между лидерами; второе
равенство возвращает стол к обсуждению.

**Мирные выигрывают, когда среди живых не осталось шпионов. Шпионы — когда их
становится не меньше, чем мирных.**

Партию закрывает досье: номер дела, победитель, состав с ролями и порядком
вылета, слово и подсказка шпиона. Единственная карточка, которую есть смысл
переслать.

«Раскрыть карты» — только ведущему: заканчивает партию досрочно, победителя у неё
нет.

## Режимы победы

- **Классика** — партия идёт, пока одна из сторон не возьмёт своё.
- **Навылет** — первый же вылет мирного отдаёт партию шпионам. Голосование без
  вылета промахом не считается.

Режим выбирается до старта и держится всю партию, включая «Ещё партию».

## Команды

| Команда | Что делает |
|---|---|
| `/start` | игра с одного телефона |
| `/undercover` | лобби в группе |
| `/undercover_stats` | зал славы чата и личная статистика |
| `/undercover_reset` | снять с чата лобби и партию; только ведущий или админ |

Зал славы считает четыре титула — шпион месяца, лучший сыщик, первая жертва,
самая длинная серия. Титул требует трёх партий в роли и хотя бы одной победы.
Партии с «Раскрыть карты» и игра с одного телефона в личный зачёт не идут.

## Конфигурация

Всё окружение — в `.env` (шаблон: `.env.example`). Неверное значение бот сообщает
на старте и завершается с кодом 1.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | токен от @BotFather |
| `POSTGRES_DB`, `POSTGRES_USER`, `POSTGRES_PASSWORD` | да | учётные данные базы |
| `POSTGRES_HOST` | да | `postgres` в compose, `localhost` локально |
| `POSTGRES_PORT` | нет | `5432` |
| `REDIS_URL` | да | FSM aiogram и состояние партий |
| `LOG_LEVEL` | нет | `INFO` |

## Словарь

Слова в поставку не входят: миграции создают пустые таблицы — `categories`
(`slug`, `title`), `words` (`category_id`, `text`, `difficulty` 1–3), `spy_hints`
(`word_id`, `hint_text`). Пока слов нет, партия останавливается на «словарь игры
пуст».

```sql
WITH category AS (
    INSERT INTO categories (slug, title) VALUES ('food', 'Еда')
    RETURNING id
), word AS (
    INSERT INTO words (category_id, text, difficulty)
    SELECT id, 'борщ', 1 FROM category
    RETURNING id
)
INSERT INTO spy_hints (word_id, hint_text)
SELECT id, 'что-то горячее' FROM word;
```

Консоль — `docker compose exec postgres psql -U undercover -d undercover`.
`title` попадает на кнопку, так что пишется по-человечески. Выбор категорий бот
предлагает от двух активных. Слово ищется в два шага — случайная категория, потом
слово в ней, — поэтому большой раздел не вытесняет маленький. Лишнее выключайте
(`is_active = false`), а не удаляйте: журнал партий ссылается на слова.

## Разработка

[Poetry](https://python-poetry.org/docs/#installation) 2.1+ и Python 3.13/3.14.

```bash
poetry install
docker compose up -d postgres redis
poetry run undercover-bot
```

Alembic настроен в `[tool.alembic]` внутри `pyproject.toml`, миграции лежат в
пакете — доступны в контейнере без исходников:
`docker compose run --rm bot alembic ...`. Карточки можно посмотреть без бота:
`poetry run python tools/card_preview.py` → `docs/preview`.

Те же команды гоняет CI (порог покрытия: 90% строк, 85% ветвей):

```bash
poetry check --lock
poetry run ruff check .
poetry run ruff format --check .
poetry run mypy
poetry run pytest                 # -m "not integration" — без Docker
```

## Ограничения

Бот рассчитан на один экземпляр: отсчёт и блокировки живут в процессе, после
перезапуска таймер молчит, но партия доигрывается кнопками. Состав фиксируется на
старте — присоединиться к идущей партии нельзя.
